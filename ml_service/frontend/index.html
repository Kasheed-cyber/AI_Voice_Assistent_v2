Как проходит проверка

  1. Для каждого разговора заранее создаётся эталонная разметка: договор, задача, срок и ответственный.
  2. Тот же аудиофайл проходит через ASR + LLM-пайплайн проекта.
  3. Результат автоматически сравнивается с эталоном.
  4. Отдельно проверяется ситуация «несколько договоров в одном разговоре».
